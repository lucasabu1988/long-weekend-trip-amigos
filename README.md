# Long Weekend Trip Planner · Los 9 🔥

Planificador interactivo para decidir el fin de semana largo entre 9 amigos desde Lima.

## 📊 Sheet de votos (fuente oficial del grupo)
https://docs.google.com/spreadsheets/d/1jnUf6ymPtCk7IKeilkYBICsOtIMFPjGXFfpA_VzeHE4/edit?usp=drivesdk

Comparte este Sheet con permisos de **Editor** a los 8 amigos.

## Las 3 opciones

### 1. Paracas + Huacachina (Recomendada)
- **Viaje**: 3.5–4 h
- **Highlights**: Islas Ballestas, Reserva Nacional, dune buggy + sandboarding, pisco, nightlife
- **Costo est.**: S/ 450–700 pp
- **Energía**: Alta

### 2. Lunahuaná
- **Viaje**: 2–2.5 h
- **Highlights**: Rafting, canopy, cuatrimotos, bodegas de pisco/vino, comida criolla
- **Costo est.**: S/ 280–480 pp
- **Energía**: Muy alta

### 3. Máncora / Punta Sal
- **Viaje**: Vuelo ~1.5 h + transfer
- **Highlights**: Playa, surf, fiestas, ceviche, total relax
- **Costo est.**: S/ 650–1,100 pp
- **Energía**: Media

## Cómo coordinar
1. Cada uno llena el Sheet (o usa el HTML interactivo para generar su resumen y pegarlo en WhatsApp).
2. Vemos el ranking y las actividades más votadas.
3. Decidimos destino.
4. Lucas arma el paquete de reservas (transporte + hospedaje + tours clave).

## El sitio interactivo
El archivo `index.html` es self-contained (Tailwind CDN + JS puro). Descárgalo y ábrelo en cualquier navegador, o súbelo a Netlify Drop / cualquier host estático. El código completo está listo en los artifacts del proyecto.
