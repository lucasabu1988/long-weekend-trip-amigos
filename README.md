# Long Weekend Trip Planner - Los 9 🔥

Sitio para coordinar el fin de semana largo entre 9 amigos.

## Cómo usarlo

1. Abre el [index.html](index.html) o visita la GitHub Pages una vez activada.
2. Explora las 3 opciones.
3. Vota y marca actividades.
4. Copia el resumen a WhatsApp o llena el Google Sheet compartido.

## Destinos

1. **Paracas + Huacachina** – Aventura clásica
2. **Lunahuaná** – Deportes + bodegas (más cerca)
3. **Máncora** – Playa y fiesta

## Después de decidir

Reservas de transporte, alojamiento y tours se coordinan una vez haya consenso.
